# BazCraft

A voxel sandbox of building, automation and engineering, by Baz Studios.

Get the **BazCraft Launcher**. It installs the game, keeps it and itself up to date, and shows
what's new in each version.

- **Windows: [download](https://github.com/Baz-Studios-LLC/BazCraft-Releases/releases/download/launcher/BazCraft-Launcher.exe)**,
  run it, and choose **Install**: BazCraft joins the Start menu and the desktop. Windows may
  first say it protected your PC: choose **More info**, then **Run anyway**.
- **Mac (Apple Silicon): [download](https://github.com/Baz-Studios-LLC/BazCraft-Releases/releases/download/launcher/BazCraft-Launcher.dmg)**,
  open it, and drag **BazCraft Launcher** onto Applications. The first time, macOS asks before
  opening an app from the internet: open System Settings, Privacy & Security, and choose
  **Open Anyway**.
- **Linux: [download](https://github.com/Baz-Studios-LLC/BazCraft-Releases/releases/download/launcher/BazCraft-Launcher-linux.tar.gz)**,
  unpack it, run **bazcraft-launcher**, and choose **Install**: BazCraft joins your app menu.

Your saved worlds and settings live apart from the game, so updates never touch them.

This repository only carries the releases; the game's source is private.
